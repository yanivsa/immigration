## 2026-05-03 - Defer Nonce Generation\n**Learning:** In Cloudflare Workers, generating cryptographic nonces via `crypto.getRandomValues` adds measurable synchronous overhead. Optimizing asset delivery by deferring generation until validating the response is `text/html` saves compute time on static resources.\n**Action:** Always verify if computationally expensive operations like nonce generation are strictly required for the specific response type, and defer them if possible.
