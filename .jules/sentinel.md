## 2026-04-26 - SSRF Bypass via Incomplete URL Validation in form submission proxy
**Vulnerability:** A Server-Side Request Forgery (SSRF) vulnerability existed where the `/api/submit-form` endpoint validated the `destination` parameter using `destination.startsWith("https://docs.google.com/forms")`. This allowed bypasses via crafted URLs such as `https://docs.google.com/forms@attacker.com`, `https://docs.google.com/forms.attacker.com`, or path traversal tricks like `https://docs.google.com/forms/../../document`.
**Learning:** `String.prototype.startsWith()` is insecure for validating URLs. An attacker can append characters or structure the URL such that it matches the prefix while changing the actual host or path to an attacker-controlled location or unintended internal endpoint.
**Prevention:** Always parse URLs using the `URL` constructor (`new URL(urlString)`) and validate individual components strictly (`protocol`, `hostname`, and `pathname`) to avoid bypasses.
